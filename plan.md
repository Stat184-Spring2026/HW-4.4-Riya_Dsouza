This document is for the plan to complete this repository and assignment.

## Goals
The goal of this project is to practice using GitHub features such as repositories, branches, commits, and pull requests. It should also show understanding of project organization.

## Needs
Nouns: Computer with RStudio installed on it, GitHub, repository, files, HW #4.3 files, branches, commits, documentation, project
Verbs: create, upload, organize, write, manage, make, open, merge

## Steps
1. Make a plan.
2. Create a GitHub repository for the assignment.
3. Upload the required files.
4. Create a new development branch.
5. Make changes in the dev branch.
6. Commit the changes with clear messages.
7. Open a pull request to merge the dev branch into the main branch.
8. Merge the pull request into the main branch.
9. Create issues to track tasks that need to be completed.
10. Close the issues using commits.
11. Update the README file.
12. Review the repository.
