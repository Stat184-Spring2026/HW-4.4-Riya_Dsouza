## Project Title

This repository was created for HW #4.4 to demonstrate the use of GitHub for version control, including working with branches, commits, issues, and pull requests.

## Overview

The purpose of this project is to use GitHub concepts in a structured way while maintaining a clear and organized repository. This includes creating and managing branches, tracking work through issues, and merging changes using pull requests. The repository contains both the source files and final outputs of the assignment, allowing users to see the full workflow. 

## Interesting Insight

One key takeaway from this project is how using branches and pull requests helps organize work and prevent mistakes in the main version of a project. By making changes in a separate branch and reviewing them before merging, it becomes easier to manage updates and maintain a clean workflow.
